Aplicação web interativa para consulta de CEPs, visualização de rotas e planejamento de viagens de ônibus e metrô, integrada com APIs REST e interface moderna.

---

## 🚀 Funcionalidades

- 🔍 **Consulta de CEP:** Busca rápida de dados de endereço por CEP.
- 🗺️ **Visualização de Rotas:** Mapeamento e estimativa de trajetos.
- 🚌 **Sequência de Ônibus e Trilhos:** Organização das etapas de transporte público.
- 🎨 **Interface Responsiva:** Suporte a alternância de temas (Dark/Light Mode).

---

## 🛠️ Tecnologias Utilizadas

- **Front-end:** React.js, Vite, CSS3 / Módulos
- **Back-end:** Node.js, Express (API local na pasta `/servidor`)
- **Deploy:** Vercel

---

## 💻 Como Rodar o Projeto Localmente

```bash
# Clone o repositório
git clone [https://github.com/ProfessorPedroMarques/Buscador-de-ceps.git](https://github.com/ProfessorPedroMarques/Buscador-de-ceps.git)

# Acesse a pasta do projeto
cd Buscador-de-ceps

# Instale as dependências do front-end
npm install

# Inicie o servidor de desenvolvimento
npm run dev
